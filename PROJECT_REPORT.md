
# CLAIMPRO – CLAIM PROCESSING SYSTEM

Project Title: Insurance Claim Processing System
Project Type: Front-End Web Development Project
Technologies: HTML5, CSS3, JavaScript
Deployment Platform: Vercel
Source Code: https://github.com/tbharati876/Insurance-Claim-Processing-System-ClaimPro

Live Website: https://insurance-claimpro.vercel.app/


## 1. Project Objective

The objective of ClaimPro is to develop a web-based claim processing system that helps an administrator manage insurance claims efficiently. The application provides a centralized interface to view claims, review submitted information, approve or reject claims, manage documents, process settlements, and generate reports.

The system aims to simplify claim management, reduce manual work, and make the claim processing workflow easier to track.

## 2. Technologies Used

- **HTML5:** Used to create the structure of the application.
- **CSS3:** Used for styling, layout, responsive design, and user interface components.
- **JavaScript:** Used to implement application functionality, data management, and user interactions.
- **LocalStorage:** Used to store claims, documents, reviews, settlements, and admin session data in the browser.
- **FileReader API:** Used to read uploaded documents and store their data for the application.

## 3. Features Implemented

### Admin Login
- Admin-only login interface.

### Dashboard
- Displays total claims, claims under review, approved claims, pending claims, and rejected claims.
- Shows settlement information and recent claim activity.

### Claim Management
- Allows the administrator to view and search claims.
- Supports filtering claims by status and claim type.
- Displays detailed information about individual claims.

### Claim Review and Approval
- Allows the administrator to review submitted claims.
- Supports approving or rejecting claims.
- Stores review comments and status updates.

### Document Management
- Supports uploading and viewing claim-related documents.
- Maintains document information associated with claims.

### Settlement Management
- Displays claims requiring settlement.
- Supports recording settlement amounts and payment information.
- Updates settlement statuses.

### Reports
- Displays claim statistics and approval information.
- Supports exporting report data as CSV.
- Provides a print option for reports.
